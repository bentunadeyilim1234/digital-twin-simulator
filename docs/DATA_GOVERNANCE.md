# Data Governance

## 1. Principles

1. **Institution-level only.** The unit of analysis is the school. Only aggregate, anonymised,
   monthly institutional indicators are accepted.
2. **Data minimisation.** No identifiers, names, national ID numbers, contact data, dates of
   birth, gender, age, ethnicity, religion, diagnoses, health or disability information,
   social-media data, or any risk/threat/dangerousness scores are collected, imported or stored.
3. **Local-first.** The application calls only its own API. There is no third-party analytics,
   no external font or CDN request at runtime, and no data is sent to external services.
4. **Provenance on every record.** Each dataset has a data class and provenance metadata;
   every row carries the data-class label.
5. **Synthetic by default.** The demonstration ships with synthetic data, labelled
   *SYNTHETIC DEMONSTRATION DATA — NOT REAL SCHOOL MEASUREMENTS*.

## 2. Data classes

| Class | Meaning | Required provenance |
|---|---|---|
| `SYNTHETIC` | Generated by `twin_engine.synthetic` from the model itself | generator settings and seed (automatic) |
| `PUBLIC_RESEARCH` | Published aggregate statistics | `source` citation |
| `AUTHORIZED_SCHOOL` | Anonymised aggregate data from a school with authorisation | `authorization_reference`, `data_controller` |

Synthetic data are produced by the model and therefore **cannot validate the model**; they only
demonstrate workflows (e.g. parameter recovery).

## 3. Import controls (`twin_engine/datasets.py`)

- **Privacy guard**: column names matching identifier or sensitive-attribute patterns (English
  and Turkish, e.g. `student`, `öğrenci`, `ad`, `soyad`, `tc`, `kimlik`, `email`, `telefon`,
  `doğum`, `cinsiyet`, `etnik`, `din`, `tanı`, `sağlık`, `sosyal_medya`, `risk_score`) cause
  the whole import to be rejected — not just the column.
- **Aggregation check**: exactly one row per period; duplicate periods are rejected because
  they suggest person-level records.
- **No silent mapping**: every column must be mapped to a model variable, a flow, a count, the
  period, or explicitly ignored; unmapped columns block import.
- **Scale validation**: normalised values must lie in [0, 1]; raw values are normalised with
  the configured (or user-specified) reference bounds and direction; clipping is reported.
- **Missing values** stay missing; they are never set to zero.
- **Small-cell suppression**: if `n_respondents < 10` for a month, survey-based aggregates
  (C, T, J, H) for that month are suppressed (default on).
- **Size limits**: ≤ 2 MB upload and ≤ 600 monthly rows.

## 4. Legal context (Turkey and elsewhere)

Personal data processing in Turkey is governed by Law No. 6698 on the Protection of Personal
Data (KVKK). The design avoids processing personal data at all; schools must still ensure that
the aggregate indicators they export cannot be linked back to individuals (e.g. very small
groups) and that collection of the underlying survey data had an appropriate legal basis and
ethics approval. Equivalent obligations apply under other jurisdictions (e.g. GDPR, FERPA).
This document is not legal advice.

## 5. Hosted deployments

- The browser sends an opaque workspace identifier (`X-Workspace-Id`) to separate scenario
  libraries. **It is not authentication.** A hosted deployment that will hold
  `AUTHORIZED_SCHOOL` data must add access control (e.g. an identity-aware proxy or platform
  authentication) before such data is imported.
- SQLite is stored on the API server's disk (`TWIN_DB_PATH`); use an encrypted volume and
  restrict access to operators.
- CORS is limited to `TWIN_ALLOWED_ORIGINS`; the frontend proxies `/api/*` server-side, so the
  browser talks only to its own origin.
- Deleting a dataset removes it from the database; project exports are user-initiated
  downloads.

## 6. Survey instruments

Belonging, trust, fairness and help-seeking should be measured with validated anonymous
instruments, e.g. the ED School Climate Surveys (EDSCLS), the Psychological Sense of School
Membership scale (Goodenow, 1993), the Turkish School Climate Scale (Çalık & Kurt, 2010) or the
Turkish adaptation of White et al.'s school climate scale (Özdoğan et al., 2025). Any newly
created questionnaire is an **experimental instrument** requiring pilot testing and reliability
and validity assessment before use; the model does not confer psychometric validity.
